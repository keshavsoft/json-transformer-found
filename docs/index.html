Follow the data through V3.

The engine starts at src/index.js and currently routes into src/v3. Its behavior is easiest to understand in three passes.

Choose the shape

Traversal dispatches by the source value: arrays go to array traversal, objects go to object traversal, and primitive values pass through.

Match source keys

At a transformed object level, V3 loops over source keys and emits the ones named by the recipe’s transform map.

Apply each rule

For each match, V3 can rename the key, recurse, wrap the value as an array, and extract a nested value.
